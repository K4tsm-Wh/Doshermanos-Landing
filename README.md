# Dos Hermanos Landing

Act as a senior frontend engineer and UI/UX designer specialized in modern industrial & B2B corporate websites.

Build a robust, responsive, and highly professional corporate landing page for Dos Hermanos (doshermanos.cl), a company specialized in heavy machinery services, industrial maintenance, and manufacturing.

Visual Identity & Color Palette:
Create a custom, grounded industrial color scheme based on warm earth/machinery tones:

Primary Base / Backgrounds: Deep espresso/dark roast brown (#1F1815 or #2A1F1B) paired with clean crisp white (#FFFFFF) and off-white/light warm gray (#F9F8F6) for alternating reading sections.

Industrial Accents:

Caterpillar/Heavy Yellow: (#EAB308 or #FACC15) for high-visibility badges, status tags, and focal highlights.

Industrial Amber/Orange: (#D97706 / #EA580C) for secondary accents, action buttons, and active tabs.

Warm Mocha / Steel Brown: (#574238 / #3E3029) for structured borders, subtle card backgrounds, and secondary typography.

Contrast & Hierarchy: High contrast readability with sharp industrial typography, modern rounded-md cards, subtle drop shadows, and clean grid alignment.

1. Navigation / Header (Sticky)
Background: Clean semi-translucent dark espresso or solid warm white with a thin border (border-stone-200 / border-stone-800).

Logo/Brand: "Dos Hermanos" with solid industrial typography (combining warm brown and yellow/orange accents).

Navigation links (smooth scroll to sections):

Inicio

Soldadura

Mecánica

Mecanizado

Granallado y Pintura

Fabricación y Mantención

Contacto

Action Buttons (Right):

Direct Phone/Contact pill button (warm brown / amber border).

Prominent WhatsApp CTA button (#25D366 accent).

2. Hero & Trust / Value Proposition Section
Hero Banner: Impactful heavy-industry hero section with a bold headline, rich dark background with subtle warm tones, and punchy value proposition focusing on precision, heavy machinery uptime, and execution standards.

Trust / Metrics Strip: A dedicated trust bar below the hero using warm sand/light coffee background (#F5F0EB) with key badges (e.g., "Normas de Calidad & Seguridad", "Trazabilidad Garantizada", "Capacidad Operativa en Terreno", "Respuesta Rápida").

3. Core Services Sections (Alternating Layouts)
Create distinct, modern section blocks (alternating between clean white and soft warm gray cards with industrial image placeholders, tag chips, and bulleted technical specs) for the following 5 divisions:

Soldadura:

Subtitle / Category: 01 — ESTRUCTURAS & CALDERERÍA

Description: Soldadura de alta resistencia, recuperación estructural y homologaciones técnicas.

Feature tags: MIG / TIG / Arco Sumergido, Recuperación Estructural, Control de Calidad.

Mecánica:

Subtitle / Category: 02 — SISTEMAS & POTENCIA

Description: Mantención y reparación integral de componentes mecánicos, transmisiones y sistemas hidráulicos pesados.

Feature tags: Mecánica Pesada, Diagnóstico & Overhaul, Sistemas Hidráulicos.

Mecanizado:

Subtitle / Category: 03 — PRECISIÓN INDUSTRIAL

Description: Tornería, fresado y mecanizado CNC/convencional para tolerancias y ajustes de alta exigencia.

Feature tags: Torno & Fresa, Mecanizado In Situ, Ajuste de Tolerancias.

Granallado y Pintura:

Subtitle / Category: 04 — PROTECCIÓN SUPERFICIAL

Description: Preparación de superficies bajo estándares SSPC/NACE y esquemas de recubrimiento epóxico y anticorrosivo industrial.

Feature tags: Granallado, Pintura Industrial, Recubrimientos Anticorrosivos.

Fabricación y Mantención de Partes y Piezas:

Subtitle / Category: 05 — INGENIERÍA Y REPUESTOS

Description: Reconstrucción, diseño y fabricación a medida de repuestos y piezas críticas para continuidad operacional.

Feature tags: Fabricación a Medida, Reingeniería de Componentes, Mantención Preventiva.

4. Contact & Location Footer Section
Deep dark coffee/espresso theme (#1F1815).

Headline: "Hablemos de tu próximo proyecto" with clear turnaround commitment text.

Left Column (Direct Info):

Email placeholder: contacto@doshermanos.cl (prominent and easily editable).

Quick action buttons for direct WhatsApp / phone contact.

Address info block with warm yellow/orange icons.

Right Column (Interactive Map Card):

Embedded Google Maps placeholder card / iframe ready for coordinates, with a styled "Ver en Google Maps" overlay button.

Floating Action: Persistent floating WhatsApp button on bottom-right (#25D366).

Technical Requirements:
Tailwind CSS using customized theme colors for warm browns, yellows, and oranges.

Modular, reusable React components (Navbar, Hero, TrustBar, ServiceSection, MapCard, ContactFooter).

Fully responsive (mobile-first) with smooth scrolling and subtle hover micro-interactions.
